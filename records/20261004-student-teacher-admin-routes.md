# 학생용·강사용·관리자용 주소 정리

- 작업일: 2026-10-04
- 학생용: `/student/` 한 주소에서 랜딩페이지와 슬라이드 연결
- 강사용: `/teacher/` 강사용 슬라이드
- 관리자용: `/admin/` 관리자 제어 화면
- 기존 루트 파일·한글 이름 파일·보존 폴더: 변경·삭제 없음

## 학생용 폴더 구성

- `student/index.html`: 학생용 랜딩페이지
- `student/slides.html`: 학생용 슬라이드
- `student/assets/`: 강사 이미지
- `student/firebase/`: 청중 동기화 파일

## 검증 기준

- 세 공개 주소 HTTP 200
- 학생용 랜딩 → 학생용 슬라이드 연결
- 관리자용 → 강사용·학생용 연결
- 휴대폰 폭 가로 스크롤 0px
